Tao Wan homepage — quick deployment

1. Put `index.html`, `stylesheet.css`, and `.nojekyll` in the ROOT of `Tao0v0.github.io`.
2. Upload your portrait as:
   assets/img/tao_wan.jpg
3. Upload a LiFR v2 teaser image as:
   assets/img/lifr_v2.jpg
   (If either image is missing, the page automatically shows a fallback placeholder.)
4. Optional CV:
   assets/pdf/Tao_Wan_CV.pdf
5. GitHub -> repository Settings -> Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save, wait about 1–2 minutes, then open:
   https://tao0v0.github.io

Because `.nojekyll` is included, GitHub Pages will serve this as a plain static site instead of processing the old al-folio/Jekyll theme.
